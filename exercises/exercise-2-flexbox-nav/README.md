# Exercise 2: Flexbox Navigation Bar

## 🎯 Objective
Use Flexbox (`display: flex`, `justify-content: space-between`, `align-items: center`, `gap`) to style a modern, clean navigation bar.

## 📋 Requirements
Inside `style.css`:
1. Style `.navbar`:
   - `display: flex`
   - `justify-content: space-between`
   - `align-items: center`
   - `padding: 16px 32px`
   - `background-color: #0b1a2c`
   - `color: #ffffff`
2. Style `.nav-links`:
   - `display: flex`
   - `list-style: none`
   - `gap: 20px`
   - `align-items: center`
   - `margin: 0; padding: 0`
3. Style `.nav-links a`:
   - `text-decoration: none`
   - `color: #ffffff`
   - On `:hover`, change color to `#f5b904`
