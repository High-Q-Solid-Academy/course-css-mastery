# 🎨 CSS Mastery & Responsive Design — High Q Solid Academy

Welcome to **CSS Mastery & Responsive Design** at **High Q Solid Academy**. CSS (Cascading Style Sheets) turns basic HTML documents into modern, responsive, visually captivating user experiences.

---

## 🎯 What You Will Master
- The **CSS Box Model** (`margin`, `border`, `padding`, `content`, `box-sizing: border-box`)
- Modern design systems with **CSS Custom Properties (Variables)** (`:root { --hq-yellow: #f5b904; }`)
- **Flexbox Mastery**: Alignment, distribution, navigation bars, cards, and wrapping
- **CSS Grid Architecture**: Two-dimensional layouts, `repeat(auto-fit, minmax(...))`, named grid areas
- **Mobile-First Responsive Design**: Breakpoints, media queries, scalable units (`rem`, `ch`, `%`, `clamp()`)
- Smooth UI transitions, micro-interactions, `:hover`, and focus accessibility states

## 🚀 How to Complete Exercises & Get Graded

1. Clone this repository to your local computer.
2. Open in VS Code and install dependencies:
   ```bash
   npm install
   ```
3. Complete the styling tasks inside each exercise folder.
4. Test your CSS locally:
   ```bash
   npm test
   ```
5. Push your code to GitHub:
   ```bash
   git add .
   git commit -m "feat: complete css mastery labs"
   git push origin main
   ```
6. GitHub Actions will verify your styles and issue your score!
